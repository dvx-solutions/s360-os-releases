# S360-OS — downloads

Instaladores do **S360-OS**, o app desktop com Agente de IA da Solução 360.

Baixe a versão mais recente em **[Releases](../../releases/latest)**:

- `S360-OS-Setup-<versão>.exe` — instalador para Windows (recomendado).
- `S360-OS-<versão>-win-x64.zip` — versão portátil: extraia e abra `S360-OS.exe`.

O instalador ainda não é assinado digitalmente: no aviso do Windows SmartScreen, clique em **Mais informações → Executar assim mesmo**.

Para entrar, use sua conta da Solução 360 (Tenant, e-mail e senha).
